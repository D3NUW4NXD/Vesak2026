Built with a midnight-blue starry sky backdrop, falling lotus petals, glassmorphism UI widgets, and full audio-visual scripting.

## 🚀 Technical Blueprint

*   **Core Engine:** Vanilla ECMAScript 6, native DOM lifecycle management, and hardware-accelerated CSS animations.
*   **Acoustic Architecture:** HTML5 Audio pipeline integrated with modern Web Audio API contexts for seamless fading transitions and linear gain protection.
*   **Typography Framework:** Deep rendering layouts combining the elegant `Cinzel Decorative` and local `Noto Serif Sinhala`.
*   **Response Blueprint:** Fluid `clamp()` typography structures and dynamic CSS Grid constraints for flawless viewing on desktop monitors and mobile touch displays.
